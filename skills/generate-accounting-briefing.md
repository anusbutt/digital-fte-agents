# Skill: generate-accounting-briefing

## Purpose

Generate a comprehensive CEO briefing that combines live Odoo financial data
with vault activity. Writes to `vault/Briefings/YYYY-MM-DD_Briefing.md`.

For each invoice overdue > 30 days: write an approval request in
`vault/Pending_Approval/` so the business owner can approve sending a reminder.

Calls `update-dashboard` skill at the end so Dashboard.md reflects the
freshly generated briefing.

---

## Input Sources (read in this order)

### 1. Vault context files
- `vault/Business_Goals.md` — monthly revenue target, KPIs, active projects
- `vault/Company_Handbook.md` — business name, owner name, tone
- `vault/Dashboard.md` (optional) — current system state, recent alerts

### 2. Odoo financial data (via odoo-mcp MCP tools)

Call `get_financial_summary` with no arguments (uses current month):
```
Tool: get_financial_summary
Input: {}
```

Expected response fields:
- `mtd_revenue` — month-to-date revenue (paid invoices)
- `total_outstanding` — sum of unpaid invoice residuals
- `paid_invoice_count`, `unpaid_invoice_count`
- `overdue_invoices` — list of `{ id, name, partner, amount, due_date, days_overdue }`
- `currency`

If `success: false` and `error: "ODOO_UNREACHABLE"`:
- Use placeholder values: `$0.00` for all amounts, note "Odoo offline"
- Still generate the briefing — never block on Odoo being offline

Call `get_invoices` for unpaid list:
```
Tool: get_invoices
Input: { "payment_state": "not_paid", "limit": 50 }
```

### 3. Vault activity (last 7 days)

Read `vault/Done/` — count files modified in the last 7 days.
Read `vault/Logs/` — scan log files from the last 7 days (files named `YYYY-MM-DD.json`).
Count action entries by type:
- `email_sent`, `email_drafted` — Email activity
- `whatsapp_reply` — WhatsApp activity
- `facebook_post`, `facebook_reply` — Facebook activity
- `instagram_post`, `instagram_reply` — Instagram activity
- `twitter_post`, `twitter_reply` — Twitter/X activity
- `linkedin_generated` — LinkedIn activity
- `odoo_create_invoice`, `odoo_post_invoice`, `odoo_record_payment` — Odoo activity

---

## Briefing Structure (write to `vault/Briefings/YYYY-MM-DD_Briefing.md`)

Use today's date in the filename: `vault/Briefings/2026-03-14_Briefing.md`.
If a file for today already exists, overwrite it.

```markdown
# {Day of week} Morning CEO Briefing
**{Full date}** | Generated by AI employee

---

## Executive Summary

{2–3 sentences summarising this week's financial performance, top priorities,
and any critical actions needed. Be direct and quantitative.}

---

## Revenue

| Metric | Value |
|--------|-------|
| MTD Revenue | ${mtd_revenue} {currency} |
| Monthly Target | ${target from Business_Goals.md} |
| Progress | {percent}% of target |
| Outstanding | ${total_outstanding} ({unpaid_invoice_count} invoices) |
| Paid This Month | {paid_invoice_count} invoices |

{If mtd_revenue >= target: "✅ On track — target met."}
{If mtd_revenue >= 0.75 * target: "🟡 On track — 75%+ of target reached."}
{If mtd_revenue < 0.75 * target: "🔴 Behind target — action may be needed."}

{If Odoo was offline: "> ⚠️ Odoo was offline during briefing generation. Revenue figures are unavailable. Run `docker compose up -d` to restore live data."}

---

## Unpaid Invoices

{If no unpaid invoices: "No outstanding invoices. 🎉"}

{If there are unpaid invoices, render as table:}

| Invoice | Client | Amount | Due Date | Days Overdue |
|---------|--------|--------|----------|-------------|
| {name} | {partner} | ${amount} | {due_date} | {days_overdue or "Not yet"} |
...

{Overdue invoices (days_overdue > 0) should be listed first, sorted by days_overdue desc.}

---

## Communications Activity (Last 7 Days)

| Channel | Actions |
|---------|---------|
| Email | {email_sent + email_drafted} sent/drafted |
| WhatsApp | {whatsapp_reply} replies |
| Facebook | {facebook_post + facebook_reply} posts/replies |
| Instagram | {instagram_post + instagram_reply} posts/replies |
| Twitter/X | {twitter_post + twitter_reply} posts/replies |
| LinkedIn | {linkedin_generated} posts generated |
| Odoo | {odoo_create_invoice} created, {odoo_post_invoice} posted, {odoo_record_payment} payments |

**Total completed tasks (Done/)**: {count of Done/ files in last 7 days}

---

## Completed Tasks (Last 7 Days)

{List up to 10 most recent files from Done/ with names only:}
- `{filename}`
...

{If more than 10: "...and {N} more. See vault/Done/ for full list."}
{If none: "No tasks completed in the last 7 days."}

---

## Proactive Suggestions

{Generate 2–4 actionable suggestions based on data. Examples:}

{For each invoice with days_overdue > 30: include as a suggestion}
- 🔴 **Invoice {name} is {days_overdue} days overdue** ({client}, ${amount}).
  Approval request created: see `vault/Pending_Approval/`.

{Based on MTD revenue vs target:}
- {Suggest pricing review if <50% target by mid-month}
- {Suggest follow-up on largest outstanding invoice}

{Based on communications activity:}
- {Suggest LinkedIn post if none generated this week}
- {Suggest social media burst if low engagement}

{If no data to suggest anything: "No proactive suggestions at this time."}

---

*Generated {ISO-8601 UTC timestamp} by AI employee (Nestaro Pilot tier)*
*Data sources: Odoo MCP ({online|offline}), vault/Done/, vault/Logs/*
```

---

## Overdue Invoice Approval Requests

For each invoice in `overdue_invoices` where `days_overdue > 30`:

1. Check if `vault/Pending_Approval/APPROVAL_odoo_send_reminder_{client_slug}*.md` already exists.
   If it does, skip (do not create duplicate).

2. Write `vault/Pending_Approval/APPROVAL_odoo_send_reminder_{client_slug}_{YYYYMMDD_HHMMSS}.md`:

```markdown
---
type: approval_request
action_type: odoo_record_payment
source_item: SYSTEM_overdue_reminder
plan_file: null
created: {ISO-8601}
expires_at: {ISO-8601 + 48 hours}
status: pending
approved_by: null
executed_at: null
invoice_name: {invoice name}
invoice_id: {invoice id}
partner_name: {partner}
amount: {amount}
due_date: {due_date}
days_overdue: {days_overdue}
---

## Overdue Invoice Reminder

**Client**: {partner}
**Invoice**: {invoice name}
**Amount Outstanding**: ${amount}
**Due Date**: {due_date}
**Days Overdue**: {days_overdue}

This invoice is {days_overdue} days overdue. Approving this request will:
1. Send a payment reminder to the client (via email or WhatsApp)
2. Log the reminder in vault/Logs/

## To Approve
Move this file to `vault/Approved/`

## To Skip
Move this file to `vault/Rejected/`
```

---

## Final Step: Update Dashboard

After writing the briefing file and all approval requests, invoke the
`update-dashboard` skill to regenerate `Dashboard.md` with fresh data.

---

## Error Handling

| Scenario | Action |
|----------|--------|
| Odoo offline (ODOO_UNREACHABLE) | Use $0 placeholders; note in briefing; continue |
| Odoo auth failed (AUTH_FAILED) | Use $0 placeholders; note "Odoo auth failed — check ODOO_API_KEY" |
| Business_Goals.md missing | Use "target unknown" for revenue comparison |
| No log files found | Show "No activity data available" in Communications section |
| Done/ empty | Show "No completed tasks in last 7 days" |
| Briefings/ does not exist | Create the directory, then write the file |

---

## Tools Required

- `odoo-mcp` (MCP) — `get_financial_summary`, `get_invoices`
- `Read` — vault context files, log files
- `Glob` — find Done/ files, Logs/ files, existing approval files
- `Write` — briefing file, approval request files
